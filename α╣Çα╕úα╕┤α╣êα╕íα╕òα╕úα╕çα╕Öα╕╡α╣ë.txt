========================================
  Green Valley Life — วิธีเล่นที่ชัวร์
========================================

วิธีที่ 1 (แนะนำ — ไม่ต้องติดตั้งอะไร)
--------------------------------------
1. เปิดไฟล์  PLAY.html  ด้วยเบราว์เซอร์
   (คลิกขวา → Open with → Chrome / Edge / Firefox)
2. กดเข้าสู่ระบบ ด้วย
   อีเมล: rachiytahs@gmail.com
   รหัส:  1369900
3. เข้าเกมได้ทันที + ปุ่มแอดมิน

หรือเปิดไฟล์ที่โฟลเดอร์ artifacts:
  PLAY-GreenValleyLife.html


วิธีเล่นในเกม
-------------
- เลือกเครื่องมือด้านล่าง: ไถ / ปลูก / รดน้ำ / เก็บ
- คลิกแปลงดิน
- คลิกไก่เพื่อเก็บไข่
- คลิกบ่อน้ำเพื่อตกปลา
- ปุ่มซ้าย: ร้าน / ของขวัญรายวัน / กระเป๋า


วิธีที่ 2 (โปรเจกต์เต็ม React+API)
---------------------------------
ต้องมี Node.js ติดตั้งบนเครื่อง

เทอร์มินัล 1:
  cd backend
  node src/server.js

เทอร์มินัล 2:
  cd frontend
  npm install
  npm run dev

เปิด http://localhost:5173
